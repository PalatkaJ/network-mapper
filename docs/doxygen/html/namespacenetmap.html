Overloads the bitwise AND operator for two IPv4 addresses.

This is useful for network address calculations, such as determining the network ID from an IP address and a netmask.

Parameters
a1The first IPv4 address.
a2The second IPv4 address.
Returns
The resulting IPv4 address after the bitwise AND operation.
